I started with this project a few weeks ago, I was thinking of learning an engine but wasn't sure to which project to focus at first,
then I found [microprose-shandalar-source](https://github.com/benprew/microprose-shandalar-source) , which is the decompilation of the Shandalar 1997, a beloved gamed
that I played I lot back in the day. So, I realize that I can use that foundation to make a 1.0 playable version and then port it to a
modern game engine.

At first, I thought about [Godot](https://godotengine.org/), a fully featured modern engine with a huge Free Software/OSS community, but then
I realize that I am not so much of a fan of the Godot Engine native language (GDScript), and also it maybe a big engine for what I want to do
with this project, so, I decided to use [Fyrox](https://fyrox.rs/), its a modern Rust engine, very well documented with nice features that can even
run in the browser, is not that well done, but this is a very nice opportunity to learn Rust in deep while porting this amazing game.
