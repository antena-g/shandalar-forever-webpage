A plane worth saving

In 1997, MicroProse released Magic: The Gathering for the PC and hid something remarkable inside it: Shandalar, a whole adventure built around the card game. You roam an overworld of towns, dungeons and castles, buy and trade cards, take on quests, and win every fight with a Magic duel, where the loser forfeits the ante.

Five Guild Lords race to cast the Spell of Dominion, not knowing that it is a trap set by Arzakon. Only you, a wandering novice spellcaster, know the truth.

What is Shandalar Forever?

Faithful to 1997

The original artwork, layouts and interaction style are the reference. Each feature is checked against the recovered 1.0 game, with traces of its behaviour and side-by-side screenshots.

Native, not emulated

No Wine and no Windows modules. The game is written in Rust with the Fyrox engine, and the same build also runs in the browser through WebAssembly.

Rules you can test

Card rules and campaign state live in a portable Rust core with no engine code inside it, so every rule can be tested headless with cargo test.

Playable today

  • Menus, difficulty, colour and character creation
  • Walking the overworld with the original movement, terrain and sprites
  • The world map (F2) that only shows what you have explored
  • Arriving at Hornwell Mill and leaving it again
  • A first bounded duel with original card art
  • The same flows in the browser build

On the road ahead

  • Town services: cards, food, quests and deck editing
  • Encounters with Shandalar's wandering creatures
  • Full duels whose results carry back into the campaign
  • Saving and loading, including original save files
  • Dungeons, castles and the Guild Lords
  • Later: new mechanics and cards, and modding support

Build & play

From the shandalar-forever/ folder:

# Native Linux client
cargo run

# A short, fixed duel
cargo run -- --duel-fixture

# Rules and campaign tests, no window needed
cargo test

# Browser build, then open http://localhost:8000/web/
bash build-browser.sh
python3 -m http.server 8000

The browser build needs the wasm32-unknown-unknown Rust target and wasm-bindgen 0.2.129. The original art is already bundled.
